# وضعیت اجرایی آغاز فاز دوم | ۱۶ اکتبر ۲۰۲۶

**نقطه شروع تأییدشده:** برنچ `research/digital-economy-extended-data` در GitHub **پیش‌تر وجود داشته** و دو commit ابتدایی آن شامل [طرح اصلی](PHASE_2_EXTENDED_DATA_RESEARCH_MASTER_PLAN_FA.md) و [قفل ۴۷ کشور](../config/extended/phase2_original_47_country_sample_lock.json) بود. در مقایسه نخست با برنچ تحقیق فاز A، دو برنچ diverged بودند؛ فاز B از **snapshot موقت و نه نسخه استادِ تحویل‌شده** منشعب شده است. این وضعیت بدون ادغام یا بازنویسی تاریخچه حفظ شد.

## اقدامات تازه تأییدشده در این مرحله

۱. **دستگاه/پروژه جدا:** کارپوشه دوم `~/research/Digital-Economy-GMM-Phase2` روی همان تبلت با `git worktree --detach` از برنچ B ساخته شد؛ کارپوشه فاز A روی برنچ `research/digital-economy-estimation-audit-20261008` باقی ماند. هیچ switch در کارپوشه فاز A انجام نشد.

۲. **قفل منبع تأیید شد:** SHA256 فایل `data/raw/Balanced_Panel_Data.xlsx` روی دستگاه با هش `474d5525a37ecfbb424c9dd25d832a9ffa6eed1942bd4f4900454204810d215b` در قفل نمونه تطبیق داشت؛ تعداد کل کشورها ۴۷ است. این فقط کنترل کیفیت منبع A/B است، نه افزودن داده خارجی.

۳. **منابع معتبر و موارد استفاده ممیزی شدند:** [SOURCE_CATALOG](../data/extended/SOURCE_CATALOG.md) با اولویت OECD ICIO، UN Comtrade، WIPO IP و WDI، تعریف واحد، خطر اندازه‌گیری و شرایط منبع/مجوز/مفقودی تهیه شد. **هیچ پوشش ۴۷×۱۸ هنوز تأیید نشده.**

۴. **پایلوت WDI کدنویسی شد:** [اسکریپت](../src/python/extended/pilot_wdi_coverage.py) برای دانلود و حسابرسی پنج شاخص WDI، نگهداری JSON خام/هش، ساخت جدول ۸۴۶ کلید بدون هیچ پرکردن missing، ثبت `coverage_summary.csv` و جدول پوشش هر کشور ایجاد شد. `python -m py_compile` روی تبلت موفق بود. از این کد **هیچ تخمین آماری اجرا نشده**.

۵. **مسیر اجرای جدا از تبلت آماده شد:** [گردش‌کار GitHub Actions](../.github/workflows/41-phase2-wdi-coverage.yml) روی برنچ B تعریف شد و فایل خروجی را فقط در Artifact موقت `PHASE2-EXPERIMENTAL-wdi-five-indicator-coverage` قرار می‌دهد. **اجرای موفق Job/دانلود واقعی JSON یا پوشش عددی هنوز راستی‌آزمایی نشده**؛ نباید موفقیت آن را پیشاپیش اعلام کرد.

## محدودیت اتصال

- درخواست مستقیم `api.worldbank.org` در Termux به خطای `URLError: No address associated with hostname` برخورد کرد؛ مشکل DNS/شبکه دستگاه، نه نتیجه آماری پوشش.
- سرویس Firecrawl متصل در بررسی تکمیلی گزارش داد سهمیه اعتبار فعلی کافی نیست و درخواست داده اجرا نشد؛ درخواست تکراری ثبت نشد.
- راهکار جایگزین ایجادشده GitHub Actions است؛ **مرحله بعد بررسی Run و Artifact**، و اگر سرویس API از GitHub Actions هم قابل دسترسی نبود، اصلاح مسیر دریافت با سازوکار مجاز/دانلود رسمی است. تا مشاهده واقعی فایل‌های حاصل، `missingness_of_external_datasets=NOT_EVALUATED`.
