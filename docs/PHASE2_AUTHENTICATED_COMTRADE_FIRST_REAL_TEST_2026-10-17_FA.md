# فاز دوم | آزمون واقعی UN Comtrade API پس از ثبت کلید | ۱۷ اکتبر ۲۰۲۶

**وضعیت:** آزمون‌های دارای مجوز واقعاً انجام شده‌اند؛ Secret به‌درستی در GitHub به گردش‌کار منتقل شد؛ هنوز دریافت **کاملاً تأییدشده تجارت ICT شش‌رقمی** موفق نشده است. **فاز اول استاد و داده خام آن تغییری نکرده‌اند.**

## ۱. تأیید اتصال و پاسخ‌های واقعی

Secret با نام `COMTRADE_API_KEY` در تنظیمات GitHub وجود دارد. صرفاً *نام و تاریخ ثبت* بررسی شد؛ مقدار حساس نمایش داده نشد.

[اولین اجرای دارای مجوز](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022066923) با خطای اعتبارسنجی علمی متوقف شد، چون فراخوانی منطبق بر **آذربایجان ۲۰۱۷، HS2017 / H5، هشت کد ICT شش‌رقمی** با HTTP 200، اما `count=0` جواب داد. **این مقدار به‌معنی تجارت صفر نیست.**

[اجرای دوم، شش سناریوی مستقل](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022128061) موفق شد و [فراداده بدون کلید و بدون صفرسازی](../evidence/extended/COMTRADE_FULL_API_HS6_EMPTY_QUERY_DIAG_2026-10-17.json) را ثبت کرد:

| درخواست | HTTP | count | تفسیر |
|---|---:|---:|---|
| آذربایجان ۲۰۱۷، H5، HS6 847130، World | ۲۰۰ | ۰ | هیچ رکوردی برای این ویرایش/ترکیب نیامد |
| آذربایجان ۲۰۱۷، H5، HS4 8471، World | ۲۰۰ | ۰ | تأیید مسئله انتخاب نسخه |
| آمریکا ۲۰۱۷، H5، HS6 847130، World | ۵۰۰ | نامعلوم | خطای سرویس؛ نتیجه علمی ندارد |
| آمریکا ۲۰۲۲، H6، HS6 847130، World | ۴۲۹ | نامعلوم | محدودیت نرخ درخواست |
| آمریکا ۲۰۲۲، `HS`، `TOTAL` واردات، World | **۲۰۰** | **۱** | **رکورد واقعی** با `classificationCode=H6` و `primaryValue=3,372,902,165,775` دلار |
| آذربایجان ۲۰۱۷، H5، HS6 847130، همه مبدأها | ۲۰۰ | ۰ | شاهد اضافه علیه H5 در آذربایجان |

این آزمون ثابت می‌کند **کلید و endpoint جامع کار می‌کنند**، نه اینکه جمع‌آوری تفصیلی ICT موفق شده باشد.

## ۲. کشف علت نبود داده و کنترل عینی سال–کشور

[اجرای موفق آزمون فراداده رسمی getDa](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022193337) با Secret در هدر HTTPS، نسخه **اصل گزارش‌شده** را از `/data/v1/getDa/C/A/HS` دریافت کرد:

| کشور / سال | ویرایش رسمی گزارش‌شده | معنا |
|---|---|---|
| آذربایجان ۲۰۱۷ | **H4** | HS 2012، نه H5 |
| آمریکا ۲۰۱۷ | **H5** | HS 2017 |
| ترینیداد و توباگو ۲۰۲۲ | **H4** | HS 2012، نه H6 |

داده منبع: [COMTRADE_AUTHENTICATED_AZE_2017_SOURCE_EDITION_CHECK_2026-10-17.json](../evidence/extended/COMTRADE_AUTHENTICATED_AZE_2017_SOURCE_EDITION_CHECK_2026-10-17.json).

پاسخ آزمون واردات چهاررقمی آذربایجان **با نسخه درست H4** بعد از تلاش مجدد همچنان **HTTP 500** بود؛ از آن رکورد قابل‌استفاده استخراج نشد. این موضوع یک مانع مجزای قابلیت اتکای API است و نباید با نبود تجارت یا نبود نسخه HS اشتباه گرفته شود.

## ۳. اصلاح واقعی کد پس از کشف اشکال

پیش‌نویس اول `preflight_free_comtrade_full_ict_hs6.py` نسخه H5 را برای ۲۰۱۷ ثابت گرفته بود و به همین علت فرض نادرست داشت. در [اصلاح کد](https://github.com/mrst10578/Digital-Economy-GMM/blob/research/digital-economy-extended-data/src/python/extended/preflight_free_comtrade_full_ict_hs6.py) انتخاب نسخه از فراداده واقعی `getDa` انجام می‌شود، **فقط یک ویرایش اصلی قابل تشخیص** پذیرفته می‌شود، کالاهای رسمی **همان ویرایش** انتخاب می‌شوند، و میان فراداده و تجارت مکث هشت‌ثانیه‌ای اعمال می‌شود. داده‌های مبهم یا پاسخ‌های ناقص رد می‌شوند.

این نسخه اصلاح‌شده **هنوز خروجی تجارت معتبر تولید نکرده است**؛ تا زمان اجرای موفق، نباید سند را نشانه دریافت داده نهایی قلمداد کرد. [کد تشخیص تکمیلی برای مقایسه درخواست یکسان preview و full](../src/python/extended/compare_comtrade_preview_vs_full.py) نیز نوشته شده، اما برای آن **اجرای موفقی ثبت نشده** است.

## ۴. نتیجه تصمیمی برای ادامه پژوهش

- **احراز هویت:** حل‌شده و آزمایش‌شده.
- **سبد رسمی ICT HS6:** ۶۹۱ سطر کد–ویرایش از هفت PDF رسمی، قبلاً استخراج شده است.
- **نسخه واقعی کشور–سال:** اثبات شد و در کد اصلاح شد؛ تعمیم مکانیکی سال به نسخه ممنوع است.
- **تجارت اصل HS6:** هنوز تأیید نشده؛ در آزمون‌های تفصیلی HTTP 500 و HTTP 429 مشاهده شده است.
- **سهمیه و نرخ:** استفاده از ۵۰۰ درخواست در روز در حساب Basic به معنای امکان درخواست‌های پشت‌سرهم بدون فاصله نیست؛ مکث، backoff و کنترل HTTP لازم است.
- **شبکه دوجانبه ۴۷ کشور ۲۰۰۵–۲۰۲۲، FTECH و GMM جدید:** هنوز ناقص است.
- **Stata:** در این مرحله نیاز نبوده و اجرا نشده است.

ادامه علمی مناسب: اعتبارسنجی پایداری فراخوانی‌های commodity-level با نسخه اصلی هر گزارشگر، سپس طراحی jobهای کوچک و قابل ازسرگیری با ثبت `HTTP status`، `count`، هش پاسخ، تفکیک World از مبدأ، و `missing != 0`. تنها پس از آن، جمع‌آوری گسترده در سهمیه حساب رایگان موجه است.
