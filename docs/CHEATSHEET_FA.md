# برگه مرور سریع دفاع | اقتصاد دیجیتال

**پروژه:** ۴۷ کشور × ۱۸ سال = ۸۴۶ مشاهده (۲۰۰۵ تا ۲۰۲۲). ایران در داده نیست. هشت شاخص WDI با ۶٬۷۶۸ تطبیق موفق با API فعلی کنترل شدند.

**دو وابسته:** رشد واقعی GDP به درصد و لگاریتم بهره‌وری (سطح بهره‌وری مثبت است). اینترنت و پهنای‌باند نماینده توسعه دیجیتال هستند، نه سنجه مستقیم انتقال فناوری بین کشورها.

**معادله مرجع:** y_it = αy_i,t−1 + βX_it + μ_i + τ_t + ε_it. برای لگاریتم Y و X سطحی، ضریب شبه‌کشش است.

**پیش از تخمین:** همبستگی Internet/Broadband برابر ۰٫۸۶۴۵، VIF خام حدود ۴ تا ۴٫۸؛ VIF دوطرفه حدود ۱٫۱. IPS/Fisher آزمون نسل اول؛ CIPS برای درنظرگرفتن وابستگی مقطعی. آزمون Pesaran CD روی FE برای رشد بسیار معنادار و برای بهره‌وری p=۱٫۴۹×۱۰⁻¹²، پس نسل اول به تنهایی قابل اتکا نیست.

**تخمین واقعی:** Python: OLS/FE با ۷۹۹ مشاهده. R: ده Difference/System GMM. gretl: dpanel با ۴ مدل اصلی و دو حساسیت. R در System دو‌مرحله‌ای ضریب اینترنت رشد −۰٫۰۲۳۴ (p=۰٫۴۲۲)، بهره‌وری −۰٫۰۰۰۵۱۳ (p=۰٫۱۵۹). اینها سند علیت نیستند.

**ابزارها:** وقفه‌های ۲ و ۳ و collapse؛ در R تعداد ابزار ۳۰ Difference و ۳۸ System؛ در gretl System اصلی ۵۲ ابزار در برابر ۴۷ کشور و نقص رتبه دارد؛ حساسیت وقفه ۲ فقط ۴۶ ابزار، ولی Sargan رد شد.

**تشخیص:** H0 در Sargan/Hansen اعتبار قیود بیش‌تعیین است، رد شدن مهم است ولی نرد شدن تأیید قطعی نیست. AR(1) در تفاضل معمولاً انتظار می‌رود، AR(2) نباید شواهد خودهمبستگی نشان دهد. Difference-in-Hansen برای زیرمجموعه معتبر ابزار باید واقعاً حساب شود؛ فعلاً انجام نشده است.

**پرسش حساس استاد:** «چرا نگفتی سرریز قطعی؟» چون ارتباط دیجیتال با تولید، اندازه‌گیری مستقیم انتقال بین کشورها یا شناسایی علی نیست. «چرا مدل نهایی نداریم؟» چون برخی آزمون‌ها رد می‌کنند، وابستگی مقطعی قوی است و gretl اصلی مشکل رتبه/تعداد ابزار دارد. «آیا Stata اجرا شده؟» خیر؛ تنها بسته اجرا آماده است.
