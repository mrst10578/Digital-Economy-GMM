# فاز دوم: داوری واقعی مسیر شبکه دوجانبه Comtrade در مقابل OECD

**تاریخ:** ۱۷ اکتبر ۲۰۲۶، در برنچ مستقل `research/digital-economy-extended-data`  
**مرحله:** داده‌سنجی و انتخاب منبع، نه مدل اقتصادسنجی. **Stata تا اینجا لازم نبوده و اجرا نشده.**

## ۱. آزمون اول: ۹ گره مفقود OECD در Comtrade

همان ۹ کشور که طبق پیوست رسمی OECD ICIO 2025 در شبکه ۸۰ اقتصاد گره مستقل ندارند: AZE, KGZ, MAC, MDA, MKD, MNG, PAN, TTO, URY. در [GitHub Actions #39016281175](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39016281175)، API عمومی UN Comtrade بدون کلید، با کلیدهای `reporterCode` عددی M49 و `partnerCode=156` (چین) به‌صورت سالیانه برای **۲۰۰۵ و ۲۰۲۲** آزمایش شد.

**نتیجه واقعی:** برای هر ۹ کشور و هر ۲ سال **۱۸/۱۸ درخواست دارای یک ردیف واقعی** و متادیتای reporter/partner/period درست بود. [۱۸ ردیف نتیجه بایگانی‌شده در GitHub](../evidence/extended/comtrade_nine_missing_oecd_reporters_2005_2022_preview.csv).

**محدودیت:** این آزمون فقط *گزارش واردات به کشور مقصد از چین، گروه گمرکی HS85 (ماشین‌آلات/تجهیزات الکتریکی)* است؛ **HS85 کالاهای ICT به تنهایی نیست** و هیچ اطلاعاتی درباره تمام ۱۸ سال، دیگر شرکای تجاری و انتقال دانش واقعی نمی‌دهد. نتیجه را به شبکهٔ ۴۷×۴۷ تعمیم ندهیم.

## ۲. آزمون دوم: روش درخواست چندسال و محدودیت API

پیش از مشاهده خروجی، آزمایش بسته‌ای ۹ کشور × ۳ درخواست، هر درخواست با ۶ سال comma-separated طراحی شد. [GitHub Actions #39016459598](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39016459598) گزارش کرد **۲۷/۲۷ درخواستِ چندساله HTTP 400** دارند. هیچ نتیجه عددی از این اجرا به عنوان «صفر تجارت» ثبت یا جایگزین نشد. علت عملی مشخص: این شیوهٔ batch برای پارامتر `period` در endpoint عمومی این ترکیب معتبر نیست.

**تصمیم:** از این endpoint عمومی برای کسب نتیجه صحیح باید در شرایط آزموده‌شده **هر سال را جدا درخواست کرد**؛ برنامهٔ جمع‌آوری ۴۷ کشور/تمام شرکا به محدودیت تعداد فراخوان و اندازهٔ خروجی برخورد می‌کند. برای استخراج جامع، API با **اشتراک رایگان مجاز و کلید محرمانه** گزینه قابل ارزیابی است. کلید باید در Secret امن ذخیره شود، نه در GitHub عمومی و نه در گزارش پژوهش. [مستندات رسمی UN Comtrade](https://uncomtrade.org/docs/un-comtrade-api/).

## ۳. آزمون سوم: تک کشور در کل دوره ۲۰۰۵–۲۰۲۲

برای راستی‌آزمایی workaround، **آذربایجان (AZE؛ M49=31) واردات گزارش‌شده از چین (M49=156)، HS85** در ۱۸ درخواست جداگانه با `flowCode=M` و سقف پیش‌نمایش ۴۰ ردیف اجرا شد. [GitHub Actions #39016613864](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39016613864) **SUCCESS**:

- ۱۸/۱۸ سال از ۲۰۰۵ تا ۲۰۲۲ یک ردیف معتبر، بدون خطای دانلود، تکرار یا سقف‌خوردن.
- ۲۰۰۵: **۲۸٬۴۳۷٬۵۹۲ دلار** واردات اسمی گزارش‌شده در HS85 از چین.
- ۲۰۲۲: **۴۷۴٬۲۲۸٬۹۵۴٫۳۱ دلار** واردات اسمی گزارش‌شده در HS85 از چین.
- **هیچ تورم‌زدایی، تبدیل دلاری به جریان حقیقی یا برآورد سرریز فناوری انجام نشده**، و تفاوت دو عدد را نمی‌توان اثر توسعه فناوری یا افزایش مقدار حقیقی نامید.
- [تمام ۱۸ ردیف مقدار واقعی + وضعیت مشاهده و منبع](../evidence/extended/comtrade_aze_china_hs85_2005_2022_singleton_verified.csv) علاوه بر artifact زمان‌دار، در برنچ فاز دوم نسخه‌بندی شد.

**محدودیت:** مشاهده یک رابطه `AZE←CHN` در همهٔ ۱۸ سال، اصلاً به معنی مشاهده شبکهٔ `47×47×18` یا اعتبار علّی نیست. همهٔ داده‌های نمونه در برنچ B هستند و به فاز اول استاد منتقل نشده‌اند.

## ۴. وضعیت OECD فایل اصلی

- [صفحه رسمی OECD ICIO 2025](https://www.oecd.org/en/data/datasets/inter-country-input-output-tables.html) و سند پیوست ۸۰ گره اقتصاد: در ۴۷ کشور اصلی فقط **۳۸ گره مستقل** حاضرند، ۹ مورد به عنوان اقتصاد مستقل غایب‌اند.
- [GitHub Actions #39016372191](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39016372191) سرور رسمی `webfs-sti.oecd.org` را برای فایل‌های ۲۰۰۱–۲۰۰۵ تا ۲۰۱۶–۲۰۲۲ بررسی کرد. فایل `ReadMe_ICIO_small.xlsx` با HTTP 200 و حجم **۳۲۸٬۴۲۲ بایت** در دسترس بود، اما **۴ فایل ZIP رسمی HTTP 403** دادند.
- این **مانع دانلود در محیط GitHub Runner** است، نه اثبات نبود فایل یا داده. هنوز حتی یک ماتریس واقعی OECD `country×sector×year` دانلود/کنترل نشده و پوشش اصلی قابل گزارش نیست.
- به همین دلیل فعلاً مسیر کدخورتر **Comtrade** برای غربال روابط کشورها ادامه پیدا می‌کند، اما منابع OECD دور ریخته نشده‌اند.

## ۵. تصمیم علمی و ابزارهای لازم برای مرحله بعد

۱. برای مدل واقعی انتقال خارجی، **فهرست کالاهای ICT با کدهای مشخص HS و نگاشت بین نسخه‌های تاریخی** انتخاب و ثبت شود؛ HS85 فعلی فقط برای آزمون API است.
۲. گزارشگر/شریک واقعی ۴۷ کشور، داده `World total` و خطای پوشش/بازصادرات کنترل شود. عدم گزارش با صفر تجارت یکی نیست؛ داده World را نباید به شریک جدا تبدیل کرد.
۳. اگر جمع‌آوری کامل با API عمومی بیش از سهمیه یا سقف ۵۰۰ ردیف شد، درخواست دسترسی با **کلید رایگان Comtrade** را انجام دهیم. نگهداری کلید فقط در Secret امن؛ هیچ اقدامی با کلید واقعی بدون مجوز کاربر صورت نگرفته.
۴. [پروتکل از پیش تعریف‌شده ساخت `FTECH` و شناسایی علّی](PHASE_2_BILATERAL_EXTERNAL_TECH_EXPOSURE_PREREG_2026-10-17_FA.md) باید پیش از اولین برآورد مبتنی بر شبکه رعایت شود.
۵. اجرای **Stata فقط بعد از ساخت مجموعه ورودی کامل، کنترل‌شده و قابل بازتولید** لازم می‌شود. هنگامی که به آن رسیدیم، **قبل از اجرا از کاربر می‌خواهیم فعالش کند**.
