## ۱. علت خطای اولیه API و روش تصحیح‌شده

در [اجرای ۷۱](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022722524)، استفاده از **`/C/A/HS` به‌معنی نسخه اصلی گزارش‌شده** پاسخ HTTP 200 داد؛ با بررسی `classificationCode` رکورد مشخص شد آمریکا ۲۰۲۲ H6 و آذربایجان ۲۰۱۷ H4 است. برای `847130` آمریکا، هر دو endpoint دقیقاً ارزش `54,530,351,570` دلار را برای World ثبت کردند.

آزمایش مقایسه‌ای آذربایجان ۲۰۱۷، کد `8471` نشان داد بدون اعلام صریح روش تجمیع ممکن است full خروجی تکراری/چندلایه بدهد. در [اجرای ۷۳](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022823344)، با **`breakdownMode=classic`**، `partnerCode=0`، `motCode=0`، `partner2Code=0` و `customsCode=C00`، دقیقاً **یک رکورد World** با ارزش `69,128,471.94` دلار دریافت شد و مقدارش با پیش‌نمایش برابر بود. **هیچ‌گاه چند رکورد هم‌پوشان World را با هم جمع نکنید.**

## ۲. نسخه HS واقعی در تمام نمونه ۴۷×۱۸

در [اجرای موفق ۷۲](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022778342)، برای **۱۸ سال ۲۰۰۵–۲۰۲۲**، فراداده `public/v1/getDA/C/A/HS` دریافت شد: **۱۸ درخواست معتبر HTTP 200**، شمار ردیف‌ها با پاسخ منبع تطبیق داده شد و هش SHA256 فایل خام هر سال نگهداری شد.

این ۱۸ پاسخ برای **۸۴۶ خانه کشور–سال** اصل نمونه استاد تحلیل شدند. روش اولیه انطباق *دقیق ISO M49* تعداد ۸۰۴ دارای نسخه و ۴۲ بدون رکورد M49 دقیق تولید کرد. با بررسی ویژه ریزواحدهای گمرکی در [اجرای ۷۶](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39023112672)، تمام ۱۸ فایل خام مجدداً با هش راستی‌آزمایی و ۴۲ خانه تفکیک شدند:

| تطبیق موجود در داده رسمی | خانه کشور–سال | وضعیت استفاده |
|---|---:|---|
| دقیق کشور اصلی ISO M49 و نسخه اصلی HS | **۸۰۴** | منبع نسخه HS تأییدشده |
| قلمرو گمرکی فرانسه 251 (به‌جای FRA=250) یا قلمرو گمرکی آمریکا 842 (به‌جای USA=840) | **۳۶** | صرفاً **نامزد غیرهم‌ارز**؛ برای همسان‌سازی خودکار با کشور اصلی مجاز نیست |
| فاقد نسخه منبع حتی با انطباق دقیق | **۶** | missing؛ مغولستان ۵ و روسیه ۱ کشور–سال |
| **مجموع** | **۸۴۶** | هر خانه با وضعیت صریح |

ادعا نمی‌کنیم کد 251 کاملاً همان فرانسه، یا کد 842 کاملاً همان آمریکا با تعریف واحد اولیه پژوهش است. این تفاوت باید در بحث سنجش جغرافیایی و آزمون حساسیت حفظ شود.

## ۳. عبور واقعی از HS4 آزمایشی به ICT HS6 رسمی

هفت کاتالوگ رسمی UNCTAD (نسخه‌های ۱۹۹۲، ۱۹۹۶، ۲۰۰۲، ۲۰۰۷، ۲۰۱۲، ۲۰۱۷، ۲۰۲۲) با **۶۹۱ ردیف کد–نسخه رسمی** و دسته پنج‌گانه ICT موجود است. [مرجع رسمی استخراج‌شده](../data/extended/official_ict_hs6/unctad_ict_goods_official_hs6_1992_to_2022.csv).

در [اجرای موفق API اصلی ۶۵](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39022943597)، **۸ کد رسمی HS6 از H4 واقعی آذربایجان ۲۰۱۷** با `classic` و فقط `World` آزمایش شد. نتیجه **۸ رکورد معتبر برای ۸ کد متفاوت**، بدون کد گمشده یا تکراری، بود. کلید صرفاً از GitHub Actions Secret خوانده شد و در داده ذخیره نشده است.

[اجرای ۷۵، ممیزی مجدد و آرشیو دائمی](https://github.com/mrst10578/Digital-Economy-GMM/actions/runs/39023033211) هر هشت رکورد را با **هش پاسخ خام، نسخه واقعی H4، کاتالوگ UNCTAD، کد سطح گمرک و حمل، و هش اصل فایل استاد** تطبیق داد:
- [هشت داده واقعی HS6 به تفکیک کالا در سال ۲۰۱۷ و فقط World](../data/extended/comtrade/authenticated_HS6_2017_AZE_source_pilot/AZE_2017_eight_HS6_world_source.csv)
- [پاسخ خام اصلی جهت بازتولید](../data/extended/comtrade/authenticated_HS6_2017_AZE_source_pilot/AZE_2017_eight_HS6_world_raw_comtrade.json)

## ۴. ممنوعیت‌های علمی همچنان برقرار

۱. استفاده از `isOriginalClassification` و `getDA` برای تعیین نسخه **واقعی کشور–سال** به‌جای فرض نسخه از سال تقویمی.  
۲. انتخاب `HS` در مسیر API و اعمال دقیق `breakdownMode=classic` با حذف/تمایز سطوح حمل و گمرک.  
۳. نگهداری کد 251 و 842 به‌عنوان قلمرو گمرکی **غیردقیق**، نه خودکار معادل FRA/USA.  
۴. نگهداری missingها و خطاهای ۴۲۹/۵۰۰ به‌عنوان خطای دسترسی یا نبود گزارش، نه ارزش تجاری صفر.  
۵. سهمیه API رعایت شود؛ داده خام و SHA به‌ازای هر درخواست ثبت شود.  
۶. بدون تطبیق هفت‌نسخه‌ای HS6، پوشش کامل ۴۷ کشور و کنترل World، سنجه FTECH نهایی یا مدل GMM معتبر قابل ادعا نیست.  
۷. فایل اولیه استاد دست‌نخورده می‌ماند؛ قبل از هر اجرای واقعی Stata باید صاحب پروژه مطلع شود.
